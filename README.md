# Canberra Explorer

A mobile-friendly Canberra and ACT research map for local history, heritage leads and urbex field notes.

## Hosting with GitHub Pages

This repository can deploy automatically from the `main` branch.

1. Open this repository on GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Return to **Actions** and wait for **Deploy Canberra Explorer to GitHub Pages** to finish.
5. The site will be published at:

   https://dominichuddleston4-sys.github.io/CBR_URBEX/

Future commits to `main` will trigger a new deployment automatically.

## Location data

Some entries are imported community research leads. Their displayed labels, coordinates, current status, ownership and access have not all been independently verified. A map pin is not permission to enter. Check official sources and land access before visiting.

## Map

The interactive map uses Leaflet with OpenStreetMap, CARTO Voyager and Esri World Imagery tile layers. Map tiles require an internet connection.
